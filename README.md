# Mis Rifas

App para el celular que lleva el registro de rifas: números, compradores, precios especiales, números fijos, abonos, sorteos semanales con historial y lo que falta por recaudar.

- Funciona sin internet una vez instalada.
- Los datos se guardan solo en el teléfono de cada persona. Este repositorio no contiene datos de nadie.
- Para respaldar: en la app, "Copia de seguridad" → "Descargar copia de seguridad".

## Instalar en el teléfono

1. Abre la dirección de GitHub Pages de este repositorio en Chrome (Android) o Safari (iPhone).
2. Android: menú ⋮ → "Agregar a la pantalla principal" / "Instalar app".
   iPhone: botón Compartir → "Agregar a pantalla de inicio".

## Publicar cambios

Después de modificar los archivos, cambia `VERSION` en `sw.js` para que los teléfonos descarguen la versión nueva, y sube los cambios a la rama `main`.

La librería `xlsx.full.min.js` es SheetJS Community Edition 0.18.5 (licencia Apache 2.0).
